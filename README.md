# OpenCV 图像基础操作演示
功能：实现图片高斯模糊、翻转、旋转、缩放
- 开发语言：Python
- 依赖库：OpenCV-Python

## 功能说明
1. 高斯模糊：对图像进行平滑降噪
2. 图像翻转：水平翻转
3. 图像旋转：围绕图片中心旋转45°
4. 图像缩放：缩小为原图一半尺寸
